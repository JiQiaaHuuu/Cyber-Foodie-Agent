# Sprint 2 迭代报告：核心业务逻辑与 DeepSeek 接入

## 目标

实现真实菜单读取、Agent 主推菜分配、DeepSeek 调用和结构化战报生成。

## 完成内容

- 接入 DeepSeek Chat Completions API。
- 增加 `real_menu.json`，覆盖 1食堂到10食堂的多菜系菜品。
- 实现用户需求基础评分：预算、口味、天气、忌口、场景和热度。
- 实现 Agent 风格加权：根据菜系关键词匹配菜单标签。
- 实现裁判 Agent，输出推荐菜、备选菜、评分、理由和风险提示。

## 风险控制

- API 调用失败时使用本地规则生成发言和战报。
- 裁判推荐范围限制在两个固定主推菜中，避免生成不存在或未辩论菜品。
