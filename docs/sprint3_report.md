# Sprint 3 迭代报告：交互体验、防御性编程与评测

## 目标

提升系统展示效果，解决一次性展示、Agent 立场漂移和菜单透明度问题。

## 完成内容

- 将一次性返回改为 NDJSON 流式返回。
- 前端逐条展示 Agent 发言，并同步显示当前发言状态。
- Agent 开赛前锁定固定主推菜，三轮保持同一推荐。
- 页面不提前展示候选菜单，只展示双方主推菜和最终战报。
- 新增评测集 `eval/evalset.json`，覆盖默认和自定义 Agent 场景。

## 验收结果

- 默认场景中，川湘火辣派固定推荐麻辣香锅，粤式清养派固定推荐云吞面。
- 自定义场景中，西北碳水派固定推荐兰州牛肉面，江浙甜鲜派固定推荐糖醋里脊饭。
